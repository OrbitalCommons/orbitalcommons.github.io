# CLAUDE.md

Static GitHub Pages site for the OrbitalCommons organisation. See README.md for layout.

- No build step, no CDNs, no web fonts, no external requests at runtime. Everything ships from
  this repository. Node and Python are for development checks only.
- Run `npm test` before pushing: `tests/check_site.py` (links, alt text, viewport, metadata) and
  Playwright checks (Chromium, Firefox, WebKit; desktop and mobile; axe; interactions). Every `.html`
  file in the repo is checked, including `tools/og.html`. Playwright reuses any server already on
  the port, so when several worktrees are active run with a distinct `PORT=41xx npm test`, or you
  will silently test another checkout. On a shared machine add `--workers=2` (as CI does); more
  parallel browsers cause page crashes that look like test failures.
- When scripting merges, look the PR number up from the branch (`gh pr view <branch> --json number`)
  rather than assuming the next number; other contributors open PRs concurrently.
- Star-map code is layered: `assets/sky-core.js` (catalogue, projection, planets, drawing) is shared
  by the hero (`sky.js`), project art (`sky-art.js`) and the explorer (`sky-explorer.js`). Keep the
  hero's per-frame cost low: Lighthouse mobile runs at 4x CPU throttle and the hero animates.
- Label anything that is an illustration rather than real software output as such.
- Other OrbitalCommons repositories with their own Pages sites (currently `rizzma`) are served at
  `/<repo>/` and shadow anything at that path here. Project overview pages therefore live under
  `projects/<name>/`.
- `OrbitalCommons/adopters` is a private repository. Never link to it or cite its contents.
- Check a repository is public (`gh api repos/OrbitalCommons/<name> --jq .visibility`) before
  linking it, and take numbers (downloads, versions, benchmark results) from crates.io or the
  project README rather than estimating.
- `style.css` is the shared design system; page-specific styles go in their own file
  (`assets/home.css` for the landing page, `projects/project.css` for project pages).
- `assets/stars.js` is generated by `tools/build_stars.py`; regenerate rather than hand-edit.
  Brand rasters and social cards come from `tools/build_brand_assets.cjs` and
  `tools/build_project_cards.cjs`; sources and accuracy are in `assets/README.md`.
- The logo is the three descending four-point stars of the OrbitalCommons GitHub avatar.
- Everything animated must respect `prefers-reduced-motion` (including changes while the page is
  open), offer a pause control, and stop when off screen or in a hidden tab.
- Pages must reflow without horizontal scrolling at 320 px wide with 200% text size.
