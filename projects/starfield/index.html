Put the sky in a coordinate system.

Space data becomes useful when time, position, and reference frame agree. starfield brings those fundamentals together, with a Skyfield-inspired API and optional data sources you can select for your application.

Bring the sky into Rust

Terminal
cargo add starfield

The default crate includes core calculations and datastore support. Add only the data sources your application needs:

Cargo.toml
starfield = { version = "0.18.1", features = ["hipparcos"] }

Select the brightest stars

Rust · synthetic catalog · no download required 
use starfield::catalogs::hipparcos::HipparcosCatalog;

fn main() {
    let catalog = HipparcosCatalog::create_synthetic();
    let bright = catalog.brighter_than(3.0);
    println!("{} stars brighter than magnitude 3", bright.len());
}

This example uses a synthetic catalog, so your first run does not depend on a large download. Move to a real catalog when you are ready to connect observations.

Feature group What it adds

jpl Horizons, Small-Body Database, Minor Planet Center, and Rubin clients.
surfaces Planetary maps, reflectance libraries, and reference spectra.
