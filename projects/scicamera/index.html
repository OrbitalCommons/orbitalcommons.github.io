Make every frame count.

Scientific imaging often calls for control over exposure, sensor modes, and the path from sensor to array. scicamera began as a fork of picamera2 and focuses on high-quality, timing-sensitive still images with minimal processing.

What this model includes

This browser illustration is independent of scicamera. Its 65 artificial stars use Gaussian profiles. Illustrative settings: 8 electrons/pixel/second background, 4-electron RMS read noise, 1 electron/ADU gain, a 100-ADU bias and 12-bit clipping at 4095 ADU. These are not specifications for any camera.

Shot noise uses Poisson sampling (a Gaussian approximation at or above 30 electrons); read noise is Gaussian. The seed is fixed for repeatability. Turning noise off shows the expected signal, rounded and clipped. There is no atmosphere, tracking error, colour filter, hot-pixel model or calibration.

The preview uses a fixed square-root stretch; the FITS file stores the linear 16-bit integer array with exposure metadata. See STScI’s introduction to gain and read noise for the underlying concepts.

scicamera runs on a Linux host with supported camera hardware and libcamera bindings. This page describes the capture workflow; it does not access your browser’s camera.

Prepare your camera host.

The project documents 64-bit Raspberry Pi OS (Bullseye or later) and x86 Ubuntu. The Python package depends on libcamera and its Python bindings, which must be installed separately for your platform.

Follow the project’s libcamera setup instructions, then install scicamera into a Python environment that can see those bindings.

Terminal
python -m pip install scicamera

Before opening a camera, confirm that Python can import both packages:

Terminal
python -c "import libcamera; import scicamera; print(scicamera.__version__)"

Capture your first array.

Python · supported camera hardware required 
from scicamera import Camera, CameraConfig

with Camera() as camera:
    config = CameraConfig.for_still(camera)
    camera.configure(config)
    camera.start()

    camera.discard_frames(2).result()
    pixels = camera.capture_array().result()
    print(pixels.shape, pixels.dtype)

    camera.stop()

The context manager handles the camera lifetime, while capture methods return results you can wait for. Available resolutions, formats, and controls depend on the camera and its libcamera driver.
