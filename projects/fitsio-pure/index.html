Space data. Pure Rust.

FITS is a foundation of astronomical imaging. fitsio-pure makes those files accessible through a Rust implementation with no C dependencies and no unsafe code. Its core works with alloc; filesystem and compatibility APIs are optional.

Terminal

Read your first FITS header

Rust · read an image from bytes 
use fitsio_pure::{hdu::parse_fits, image::read_image_data};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let bytes = std::fs::read("image.fits")?;
    let fits = parse_fits(&bytes)?;
    let image = read_image_data(&bytes, fits.primary())?;
    println!("{} HDUs; pixels: {image:?}", fits.hdus.len());
    Ok(())
}

read_image_data returns raw typed pixels. Apply header scaling when you need calibrated values. In a browser, provide the file’s bytes instead of reading from a filesystem.

One format, many kinds of data

Feature Default Purpose
std Yes Standard library support.
compat No A familiar fitsio-style API, including in-memory files.
array No ndarray integration, with the compatibility layer.
cli No The fitsinfo and fitsconv command-line tools.

Image types include unsigned 8-bit, signed 16/32/64-bit, and 32/64-bit floating point. The core also reads RICE_1 and GZIP_1 tile-compressed images. Read the migration guide →
