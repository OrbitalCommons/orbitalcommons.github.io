Find your place among the stars.

A sky image has an address, even when you do not know where the camera was pointing. zodiacal matches four-star patterns against a prebuilt catalog index, fits a sky projection, and verifies the proposed alignment.

01

No pointing prior

Start from an astronomical image or a list of detected source positions.

02

Multi-scale search

Match geometric patterns across indexes covering different angular scales.

03

A verified solution

Fit a TAN-WCS projection and evaluate the alignment against catalog positions.

See it in practice

Rotate or resize this four-star pattern. The distances change together, so their ratios stay the same. Geometric invariants make a pattern recognizable before its orientation or scale is known.

The geometry of recognitionInteractive illustration

AC / AB = 1.3086 in both frames.

An illustration of geometric invariance, not a plate solve. Zodiacal uses normalized four-star hash codes, catalog indexes, projection fitting, and verification. A distance ratio alone is not enough to identify a field.

Start building

Library
cargo add zodiacal

To use the published command-line solver, install with the CLI feature:

Terminal
cargo install zodiacal --features cli --locked

From an idea to a few lines of code

A solve needs an image and a matching-scale index. Index files contain catalog star positions and geometric hashes; the package does not bundle an all-sky index.

Terminal · after building an index 
zodiacal solve image.png \
  -i my_index_00.zdcl \
  -i my_index_01.zdcl \
  --timeout 60
  1. Extract sources

    Find candidate point sources in the image.

  2. Match patterns

    Form quads and search a kd-tree of catalog patterns.

  3. Fit the sky

    Use matched correspondences to compute a TAN-WCS projection.

  4. Verify

    Check the proposed alignment against known catalog positions.

Choose what you need

Index choice matters: its angular scales must cover the field you want to solve. Build index files from a starfield binary catalog, and keep field size, limiting magnitude, memory, and search timeout in mind.

Input / output Description
Image or source list An astronomical image, or detected source positions.
Catalog index Prebuilt .zdcl files covering the relevant angular scales.
WCS solution Pointing, orientation, and plate scale in a tangent-plane projection.
Verification A catalog-based log-odds check of the proposed match.
