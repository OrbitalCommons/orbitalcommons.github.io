starfield

Astronomical data reduction toolkit in Rust. Star catalogs, coordinate systems, ephemerides and star finding, inspired by Skyfield.

Rust7,725 downloads0.18

source · crates.io · docs

What it does

  • Celestial coordinate transformations.
  • Star catalog management for Hipparcos and Gaia.
  • Precession, nutation and earth-rotation calculations.
  • Time and date handling for astronomical work.
  • Planetary constants: NAIF text kernel parsing, plus an embedded IAU 2015 table of radii and rotational elements.
  • Body-fixed reference frames from the IAU rotational elements, matching SPICE IAU_MARS, IAU_MOON and the rest.
  • Synthetic catalog generation for testing, and optional Python interop for comparing results against Skyfield.

Install

One facade crate, with feature groups so small consumers avoid unrelated dependencies.

starfield = { version = "0.18", features = ["catalogs", "jpl"] }

Defaults enable core calculations and datastore support. Optional groups are catalogs, jpl and surfaces; individual features such as hipparcos narrow it further. The release family contains six packages: starfield, starfield-core, starfield-catalogs, starfield-jpl, starfield-surfaces and starfield-tools.

Example

use starfield::time::Time;
use starfield::catalogs::hipparcos::HipparcosCatalog;
use starfield::catalogs::StarCatalog;

let catalog = HipparcosCatalog::create_synthetic();
let time = Time::now();
let bright = catalog.brighter_than(3.0);
println!("Found {} bright stars at {}", bright.len(), time);
