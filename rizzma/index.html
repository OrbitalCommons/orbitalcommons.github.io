rizzma

A Rust reimplementation of the good parts of matplotlib and pyplot, with first-class WebAssembly support.

Rust1,885 downloads1.13.3

source · crates.io · docs · live demos · gallery

Figures that stay alive

The object model mirrors matplotlib, with Figure, Axes and Artists behind a thin pyplot-style stateful facade. A single Renderer trait drives several targets: a tiny-skia raster backend for PNG, an SVG emitter, and a browser <canvas> backend. The same figure, rendered anywhere.

On the API docs the demo grid at the top of the page is not a set of screenshots. Each cell is a real canvas driven by this crate compiled to WebAssembly, animated from Rust every frame: wheel to zoom at the cursor, drag to pan, double-click to reset.

Scope

  • One figure per Tier-1 plot type in the gallery, auto-rendered on every push to main.
  • Raster, vector and canvas output from one description of a figure.
  • Interactive panning, zooming and streaming strip charts in the browser.

Install
