# Star-map data and sources

Everything the star maps draw is computed in the browser from the files here. Nothing is fetched
from third parties at runtime.

## `stars.js`

Generated by `tools/build_stars.py`:

```sh
python3 tools/build_stars.py hip_main.dat constellationship.fab > assets/stars.js
```

**Stars.** The Hipparcos main catalogue, ESA 1997, CDS catalogue I/239:
<https://cdsarc.cds.unistra.fr/ftp/cats/I/239/hip_main.dat> (the file used had SHA-256
`58ceabb104d647160d9437ce6e513a02a036bb4ad9f8879a5a22fd52943616e0`). Positions are the ICRS
J1991.25 catalogue values (fields RAdeg, DEdeg) with no proper-motion propagation; colours are
the B−V index (field 37, 0.6 where missing). The script keeps every star with V ≤ 6.3 plus any
fainter star used by a constellation figure: 7,038 stars.

**Constellation figures.** Stellarium's `constellationship.fab` as shipped in Skyfield's test
data, `ci/constellationship.fab` in <https://github.com/skyfielders/python-skyfield>, last changed
in commit `c33b825944811abd76654759771779c3c49c3d63` (SHA-256
`ea70df9c191baeffe3b45eea21396341600c42718ca9c62292ce1ca8faa9526c`). Lines refer to Hipparcos
numbers and are stored as pairs of indices into the star list.

**Names.** The 36 proper names in `NAMES` in the build script, checked against HIP numbers.

**Encoding.** `stars` is a flat array of four integers per star, sorted brightest first:

| Value | Stored as | Resolution |
|-------|-----------|------------|
| Right ascension | degrees × 20 | 0.05° |
| Declination | degrees × 20 | 0.05° |
| V magnitude | × 10 | 0.1 mag |
| B−V colour index | × 100 | 0.01 mag |

0.05° is fine for drawing and for the synthetic plate-solving frames, which use the same
quantised positions on both sides, but these values are not an astrometric catalogue.

## Planets (`sky-core.js`)

Geocentric positions from the Keplerian elements and rates in E. M. Standish, *Keplerian Elements
for Approximate Positions of the Major Planets*, JPL Solar System Dynamics, Table 1 (valid
1800–2050): <https://ssd.jpl.nasa.gov/planets/approx_pos.html>. Heliocentric ecliptic positions
of each planet and the Earth–Moon barycentre are rotated to the J2000 equator with obliquity
23.43928°. No light time, aberration, nutation or precession is applied, so positions are in the
same J2000 frame as the stars. JPL quotes heliocentric errors up to about 600″ (Saturn) over
1800–2050. Compared with Skyfield's astrometric ICRS positions from DE421 for 2026-10-04 01:00 UTC
the geocentric differences were Mercury 5″, Venus 29″, Mars 2″, Jupiter 88″, Saturn 305″,
Uranus 9″ and Neptune 29″.

## Drawn but not measured

- The Milky Way glow is an illustration: soft blobs along the galactic equator (pole RA 192.859°,
  Dec 27.128°; centre RA 266.405°, Dec −28.936°), brighter toward the centre. It is not built
  from survey data.
- Star sizes, colours and twinkle are styling derived from V and B−V.
- On the homepage, the automatic box-and-quad sequence is an illustration. Clicking the sky runs
  the real zodiacal solver on a synthetic frame (see `demos/zodiacal-solver`).

## Other files

The quad role palette follows the canonical convention in
[CosmicFrontierLabs/cfl-manimations, zodiacal_solver.py](https://github.com/CosmicFrontierLabs/cfl-manimations/blob/289d3ab6e113057712a38a2f9a42833df8839069/zodiacal_solver.py):
A `#FC6255`, B `#83C167`, C `#58C4DD`, D `#FF862F`, A–B baseline `#FFFF00`,
A–C/A–D reference lines `#58C4DD`, and a dashed `#888888` diameter circle.
Letters accompany the colors. The real solve replay uses the upstream solver's
canonical winning correspondence; scrolling index rows are sampled records,
not a recording of the KD-tree traversal.

`og.jpg` is a 1200×630 capture of `tools/og.html`; `noise.png` is a 48×48 random dither tile;
`mark.svg`, `favicon.svg` and `apple-touch-icon.png` are the logo.

## Identity

`mark.svg` redraws the three descending four-point stars from the
[OrbitalCommons GitHub organization avatar](https://github.com/OrbitalCommons).
The curves and spacing are refined for a narrow vertical mark beside the
wordmark. `favicon.svg` uses slightly broader stars for small sizes on an opaque
dark background. These are editable vector paths, with no font dependency.

With the local preview server running, regenerate the raster brand assets:

```sh
node tools/build_brand_assets.cjs
node tools/build_project_cards.cjs
```

The first command renders the 180-pixel Apple touch icon and the 1200 × 630
homepage card; the second refreshes the six project cards. Set `CHROME_PATH` for
a system Chrome or `SITE_URL` for a different local preview address. The
homepage card fixes `Math.random` at 0.35 and captures the illustrative quad
after 12 seconds of animation, when the index replay has reached its matched row.
