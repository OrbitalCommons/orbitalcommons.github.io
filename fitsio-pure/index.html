fitsio-pure

A pure Rust implementation of the FITS file format. No C dependencies, no unsafe code, and fully compatible with wasm32 targets.

Rust3,136 downloads

source · crates.io · docs

Why pure Rust

The established fitsio crate wraps the C library cfitsio, which needs a system-level install and a C toolchain. That costs you:

  • Cross-platform builds. cfitsio has to be installed separately on macOS, Windows and Linux. This builds with cargo build anywhere, with no external dependencies.
  • Build time. No C compilation step, no pkg-config, no linking against system libraries.
  • WebAssembly. Compiles straight to wasm32-unknown-unknown with --no-default-features.
  • Cross-compilation. cargo build --target aarch64-unknown-linux-gnu just works.

In-memory files

The compat FitsFile works entirely in memory, which fitsio cannot, because cfitsio needs a path. Open bytes you already hold, such as an upload, a network response or an embedded asset.

use fitsio_pure::compat::fitsfile::FitsFile;

let fits = FitsFile::from_bytes(uploaded_bytes)?;
let hdu = fits.hdu(1)?;
let prob: Vec<f64> = hdu.read_col(&fits, "PROB")?;

cargo add fitsio-pure
