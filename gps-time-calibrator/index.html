GPS Time Calibrator

A precision timing system that pins camera timestamps to GPS, so frames taken on different machines in different places can be compared to each other.

VerilogC / ESP-IDFHardware

The problem

An imaging system is only as good as its clock. If you want to correlate a frame against an ephemeris, triangulate an event across two stations, or measure how long something took, the camera's idea of “now” has to be right to better than a millisecond. Operating system clocks are not, and network time over a consumer link drifts by more than the thing you are trying to measure.

GPS already broadcasts a disciplined one-pulse-per-second signal accurate to tens of nanoseconds. The work is getting that accuracy from the antenna to the frame.

How it works

The device is built on the IcedEspresso board: an ESP32-S2 beside a Lattice ICE40UP5K FPGA. Each half does what it is actually good at.

  • The FPGA does the timing. An interval counter measures clock cycles between PPS edges at 48 MHz. A rolling frequency averager turns that into a stable estimate of the local oscillator's true rate, and a health monitor requires a run of consecutive good pulses before it will report lock.
  • The microcontroller does everything else. It parses the GPS serial stream, manages WiFi, and serves the result as a Stratum 1 NTP server with sub-microsecond precision.
  • They talk over SPI. A register interface with value latching, so a read never catches a counter mid-update across the clock domain boundary.

Each Verilog block, counter, health monitor and averager, has its own testbench. The timing path is the product, so it gets tested like one.

Platform

The build is managed by Affogato, which wraps Yosys, nextpnr, icestorm and ESP-IDF in one container and one command. The bitstream is embedded in the ESP32 firmware at compile time and soft-loaded over SPI at boot, so there is no separate FPGA programmer in the loop. There is a longer write-up of that platform in Putting an FPGA Inside a Microcontroller Workflow.

Status

Working hardware and firmware. The source is not open at the moment, unlike the rest of the projects here. If a GPS-disciplined timebase would be useful to you, get in touch.
